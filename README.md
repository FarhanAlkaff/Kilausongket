# KILAU SONGKET - Digital Storefront & Product Catalog

Landing page dan katalog digital modern untuk **Kilau Songket** — butik busana songket nusantara premium khusus setelan anak-anak dan dewasa dengan integrasi pemesanan via **WhatsApp** dan **Shopee**.

---

## 🌟 Fitur Utama

1. **Brand Identity & Logo Resmi**
   - Logo resmi Kilau Songket terpasang di Navbar, Hero, dan Footer.
   - Konsep visual mewah: *Modern Minimalist, Deep Forest Green (#263B32), Champagne Gold (#C5A46D), Warm Ivory (#F7F4EE)*.

2. **Hero Section Elegan**
   - Headline: *"Keanggunan Warisan Songket untuk Seluruh Generasi"*.
   - Dual Call to Action: *Jelajahi Katalog* & *Konsultasi WhatsApp*.
   - Value pill: *Furing Katun Silky Anti-Gatal untuk Anak*, *Ready Stock & Custom Size*.

3. **Kategori Busana**
   - **Songket Anak (1 - 12 Tahun & Balita):** Nyaman, adem, furing ganda anti-gatal untuk karnaval & acara adat.
   - **Songket Dewasa (Pria & Wanita):** Kebaya kurung modern & kemeja songket berwibawa.
   - **Sarimbit Keluarga:** Setelan serasi ayah, ibu, dan anak untuk hari raya & resepsi pernikahan.

4. **Katalog Produk Interaktif**
   - Filter Kategori: *Semua*, *Anak-anak*, *Dewasa*, *Sarimbit*.
   - Sub-filter jenis produk (*Anak Laki-laki*, *Anak Perempuan*, *Dewasa Wanita*, *Dewasa Pria*).
   - Fitur pencarian instan (nama produk, motif, bahan).
   - Pengurutan (*Rekomendasi*, *Terlaris*, *Harga Terendah*, *Harga Tertinggi*).

5. **Modal Detail Produk & Panduan Ukuran**
   - Galeri foto dengan thumbnail preview.
   - Pemilihan ukuran interaktif (*Anak: XS, S, M, L, XL* / *Dewasa: S, M, L, XL, XXL, Custom*).
   - **WhatsApp Direct Order:** Mengirimkan pesan otomatis yang langsung terisi dengan nama produk dan ukuran yang dipilih.
   - **Shopee Integration:** Tombol beli langsung ke toko/produk di Shopee.
   - **Modal Panduan Ukuran (Size Guide):** Tabel ukuran lingkar dada, panjang baju, pinggang, dan celana/rok.

6. **Keunggulan Toko & Jaminan Mutu**
   - Furing katun silky anti-gatal, tenun benang emas Grade A, jahitan rapi setara tailor, garansi tukar ukuran.

7. **Testimoni & Kisah Nyata Pelanggan**
   - Ulasan terverifikasi untuk acara wisuda, karnaval sekolah, pesta adat, dan sarimbit keluarga.

8. **Banner Promosi & FAQ Interaktif**
   - Penawaran diskon paket seragam keluarga.
   - Accordion FAQ untuk pertanyaan umum seputar ukuran, bahan, dan pengiriman.

9. **Floating WhatsApp Widget**
   - Tombol mengambang di pojok kanan bawah dengan status "Online" dan pilihan topik chat cepat.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Asset Logo:** `public/images/logo.jpg`

---

## 🚀 Cara Menjalankan

### 1. Menjalankan Server Development:
```bash
npm run dev
```
Buka browser pada `http://localhost:3000`.

### 2. Build untuk Production:
```bash
npm run build
npm run start
```
